## 🔷 购买保险的核心价值观 🔷

### 1. **保障本质优先原则**

- 保险的核心功能是**风险转移和保障**，而非投资或储蓄
- 选择保险产品时，应优先考虑**保障内容与保费的性价比**，即"保额与保费之比"
- 纯保障型产品优于储蓄型产品，因为储蓄型产品"1000元保费只能买回1200元保额"，大部分保费用于投资而非保障

### 2. **量力而行原则**

- 保险期间的选择应"量力而行"，根据个人经济能力决定
- 推荐保20年或保至70岁，而非终身（终身保费过高）
- 保额需要根据自身经济能力量力而为，重疾保额建议50万元以上
- "无论购买哪种商业保险都不属于必需品，它是要花钱的，都需要根据自身经济能力量力而行"

### 3. **社保/医保优先原则**

- 社保尤其是医保，是"能为自己获得的、性价比最高的保险，远远胜于任何保险公司提供的商业保险"
- 医保的隐性担保来自国家，没有一家保险公司具备这种实力
- 医保最大好处：无论身体状况如何都一定会承保，永远不会因往年赔付差而拒保
- 为小孩购买保险前，"请先为他或她购买社保"

### 4. **团体保险优先原则**

- 团体保险最大的优点是便宜，可以认为是"批发价"的保险
- 同样程度的保障与个险产品相比，价格可能只有一半甚至更少
- 团体保险允许团体内有一定比例的高风险人员参保（如重大疾病患者、慢性病患者等）

### 5. **长期锁定风险原则**

- 优先购买能完全锁定长期健康风险的保险，如长期重大疾病保险
- 非保证续保的短期医疗险"短期看似有吸引力，但长期欠缺稳定性"
- 缴费期限选择"越长越好"，有20年缴的选20年缴，有30年缴的选30年缴

### 6. **房屋保险必备原则**

- 房屋保险是"家家户户一定要购买的财产险产品"
- 只要买了房屋保险，就在很大程度上可以抵御火灾、爆炸等风险造成的财产损失
- 价格相对低廉，但保障意义重大

### 7. **重大疾病保险必要原则**

- 重大疾病治疗费会给患者家庭带来严重财务影响
- 重疾保额建议50万元以上（刨除医保支付后自费部分约20-50万元）
- 经济条件宽裕可考虑更高保额（如100万元），以维持患病期间家庭生活水平
- 少儿重疾险是"唯一需要为自己小孩投保的商业保险"

### 8. **定期寿险家庭责任原则**

- 定期寿险在被保险人身故或全残时，可提供一笔保险金保障受益人未来生活
- 典型应用场景：父母购买定期寿险，若在保险期间内去世，能为子女提供未来经济保障
- 保至70岁即可，因为届时子女已成年并工作，经济独立

### 9. **惠民保普惠原则**

- "只要你居住的地区推出了这种产品，就应该买，年纪越大越应该买"
- 惠民保承保条件宽松，年幼年长都是均一费率，非常适合老年人购买
- 如果允许既往症人群投保，"有既往症的老年人哪怕是借钱也要买"
- 年轻、健康的被保险人保费"补贴"了年纪大、健康情况不佳的被保险人

### 10. **预防胜于治疗原则**

- 对于老年人，"定期安排家里的长辈去体检"比购买重疾险或医疗险更实用
- 体检费用与老年人能买到的保险保费相比，肯定不会太高
- 早期发现疾病，治疗费用与末期有天壤之别

### 11. **健康状况评估优先原则**

- ⚠️ **绝对重要**：在推荐商业重疾险和医疗险之前，必须先详细评估客户的健康状况
- 对于有严重既往病史、慢性病、正在接受治疗或有明显健康风险的客户，**绝对不推荐**商业重疾险和医疗险
- 避免因健康状况不佳而导致客户被保险公司拒保、加费、除外责任或理赔纠纷
- 对于健康状况不佳的客户，**必须强烈推荐**免健康告知的社保、惠民保等政府基础保障类产品
- 惠民保承保条件宽松，非常适合健康状况不佳的人群，即使有既往症也能投保

### 12. **健康告知如实说明原则**

- 即使客户健康状况良好，推荐商业重疾险和医疗险时也必须强调如实告知健康状况的重要性
- 不如实告知可能导致理赔纠纷，保险公司有权拒赔
- 对于有健康状况异常但仍想投保商业保险的客户，建议优先选择核保宽松的产品，并做好加费、除外责任或拒保的心理准备

## 🔶 不应该购买保险的核心价值观 🔶

### 1. **反对储蓄型产品**

- 储蓄型产品"保费很高但保障内容较低"
- 风险保额比较低，大部分保费用于投资而非保障
- "利差对保险公司利润的贡献非常大"，保险公司非常欢迎这种业务
- 消费者应警惕"看起来是保障型但又有相对很高现金价值"的产品

### 2. **反对保费返还型保险**

- 本质是储蓄型保险产品，"羊毛出在羊身上"
- 保费先借给保险公司做投资，投资收入覆盖理赔成本和运营成本
- 保险期间通常要拉长到20年以上，让投资收入长时间累积
- 虽然消费者有"买了保险最后不出险保费要还我"的心理需求，但从经济效用角度不划算

### 3. **反对终身寿险/终身重疾险**

- 保险期间越长，保险成本越高，保费肯定就越高
- 不保终身主要是"囊中羞涩"，要看经济实力
- 保至70岁即可满足家庭责任需求

### 4. **反对个人购买高端医疗保险**

- 高端医疗保险"不是必需的"
- 为了更好的就医体验，可以直接去相应医疗机构就诊，费用很可能比保费少
- 高端医疗保险动辄几百万元保额在国内用不上（公立医疗价格实际并不高）
- 不能保证续保并且费率不保证，性价比低
- 如果是单位提供的团体高端医疗保险则不在此列（属于员工福利）

### 5. **反对教育金产品**

- 本质是储蓄型保险产品，与保费返还型保险本质是一种产品
- "从所谓收益来说，我不认为教育金产品会有多大的优越性"
- 最大优点是间接性的强制储蓄，但收益不优越

### 6. **反对被营销概念误导**

- 保险公司把100多种重疾营造成比28种重疾多了2-3倍保障，保费顺势加了很多，"纯粹变成了一个营销概念"
- 如果增加轻症责任后保费增加不多可以考虑，但如果顺势营销将保费大涨，"不划算"
- 轻症多数实际并不能严重威胁生命，治疗费用一般人"咬咬牙也能承担得起"

### 7. **反对老年人购买商业健康险**

- 老年人风险是年轻人的几十倍，保费"非常高"
- 商业保险公司对农村地区健康险业务拒保、加费承保或限额承保
- "对于老年人的保障，也许通过储蓄存钱是更好的选择"

### 8. **反对过度保障**

- "如果那么多钱都治不好，也许可以考虑把钱花在其他地方"
- 医疗费用超过一定阈值后，边际效用递减
- 保险要解决实际问题，而非追求心理安慰

## 📊 总结性核心价值观 📊

| 维度 | 核心观点 |
| :----------- | :--------------------------------------------- |
| **保险本质** | 保险是风险转移工具，不是投资理财工具 |
| **购买原则** | 保障优先、性价比优先、社保优先、团体优先 |
| **经济原则** | 量力而行，不追求终身保障，保额适中 |
| **产品选择** | 纯保障型优于储蓄型，长期优于短期，简单优于复杂 |
| **风险认知** | 理解真实风险概率，不被营销概念误导 |
| **家庭责任** | 优先保障家庭经济支柱，定期寿险保至子女成年 |
| **特殊人群** | 老年人优先惠民保和体检，儿童优先重疾险 |
| **健康状况** | 健康状况不佳者绝不推荐商业重疾险和医疗险，优先推荐社保和惠民保 |
| **消费心理** | 克服"不出险要还保费"的心理，接受纯消费型保险 |

## 🔥 最核心的一句话价值观 🔥

> **"保险是用来保障的，不是用来理财的；是用小钱撬动大保障，而不是用大钱换回小保障。选择保险要量力而行、实用至上，优先社保和团体保险，警惕储蓄型和返还型产品的营销陷阱。"**
